# 画像素材の生成プロンプト

猫本体は `cat-sprite-prompt.md`。ここではそれ以外の素材のプロンプトをまとめる。
3×3のシートは、出力後に `tools/build_cat_sheet.py` に通して背景除去とセルの整列を行う
（純白のベタ背景・市松模様のどちらでも自動判定して除去する）。

## 部屋の小物 9種（`images/items.png`／使用中）

```
同じ画風の猫用の小物を9種類、3×3のグリッドに並べた1枚のスプライトシートを作ってください。

【画風（猫のイラストと統一）】
・フラットなベタ塗りのアニメ・絵本調、影やグラデーションは最小限
・輪郭線：こい茶色の太い線（はっきり見える太さ）
・高コントラストで、形がはっきり分かるシンプルなデザイン
・色みはクリーム・オレンジ・木の茶色・赤・青を基調にした、あたたかい配色
・写実的でない、かわいらしいマスコット的なデザイン

【9マスの小物】（左上から右方向の順）
上段左：赤いふかふかのクッション（座布団）
上段中央：オレンジ色の毛糸のボール（毛糸の端が少し垂れている）
上段右：チューリップが3本ささった白い花瓶
中段左：焼き魚が1匹のった白いお皿（猫のおやつ）
中段中央：茶色いかごの猫用ベッド（中にクリーム色の敷き布）
中段右：ねこじゃらし（木の棒に羽根がついた猫用おもちゃ）
下段左：水が入った青いお皿
下段中央：木でできた小さなキャットタワー（2段）
下段右：灰色のおもちゃのネズミ（しっぽは紐）

【大きさの決まり（重要）】
・9つの小物は「同じ部屋に置かれている」想定で、相対的な大小関係を正しく描くこと
　（おもちゃのネズミは小さく、キャットタワーは大きく）
・いちばん大きい小物がマスの8割程度になる大きさにそろえる
・すべての小物は地面に置かれている想定で、床に接する面を下向きに描く

【レイアウトの厳守事項】
・正方形の画像、3列×3行の均等な9マス（各マスも正方形）
・背景は完全な透過（PNG）。透過にできない場合は真っ白な単色背景
・グリッドの枠線・区切り線・番号・文字・ロゴは一切描かない
・各マスの中央に小物を1つだけ配置し、マスの枠に触れないよう周囲に余白を空ける
・となりのマスにはみ出さない、背景に影を落とさない
・猫は描かない

【サイズ】
・1536×1536ピクセル（1マス512px）
```

## 部屋の背景（`images/room.jpg`／使用中）

```
高齢者向けの猫のお世話ゲームの背景になる、明るく暖かい部屋のイラストを作ってください。

【内容】
・洋室のリビング。上側60%がクリーム色の壁、下側40%が明るい木の床
・壁と床の境目に、白い幅木（はばき）を一本入れる
・壁の左上に、青空とやわらかい雲が見える四角い窓（白い窓枠、開いたカーテンは薄いクリーム色）
・全体に、やさしい朝の光が入っているような明るさ

【画風】
・フラットなベタ塗りのアニメ・絵本調、影やグラデーションは最小限
・輪郭線は少なめで、面で見せる。装飾は最小限で、うるさくしない
・彩度を抑えたあたたかい配色（キャラクターが前に立つので、背景は静かに）

【レイアウトの厳守事項（重要）】
・画面の中央下は、キャラクターが立つ場所なので、家具や模様を一切置かず床だけにする
・四隅にも家具や模様を置かない（あとから小物のイラストを重ねるため）
・文字・ロゴ・人物・動物は描かない
・画面のどこを切り取っても成立するよう、重要な要素を中央寄りに収める

【サイズ】
・1536×1152ピクセル（横4：縦3）
```

背景は透過が不要なので、JPEG（quality 88 前後）で保存するとPNGの約1/4のサイズになる。
`background-position: left bottom` で表示するため、**窓は左寄せ**で描いてもらうとよい。

## ホーム画面アイコン（`images/icon-*.png`／使用中）

実際に使っているアイコンは茶白（ちゃしろ）の猫。既定の猫（キジトラ）に合わせたい場合は、
毛色の行を「茶色と黒の縞模様（キジトラ）、口のまわりと胸は白」に差し替えて作り直す。

出力後は、OS側で角が丸く切り取られても白い角が残らないよう、角丸の外側の白を
背景色で塗りつぶして全面塗りにし、512 / 192 / 180 / 32px に縮小して使う。

```
スマートフォンのホーム画面に並ぶアプリアイコンを作ってください。

【内容】
・かわいい子猫の顔のアップ（正面向き、にっこり笑っている）
・毛色：茶色と黒の縞模様（キジトラ）、口のまわりと胸は白
・輪郭線：こい茶色の太い線。目は大きく、黄緑色
・背景は、やわらかいクリーム色（#FFE9C7）の単色ベタ塗り（透過にしない）

【画風】
・フラットなベタ塗りのアニメ・絵本調、影やグラデーションは最小限
・遠くからでも猫だと分かる、高コントラストでシンプルな形
・写実的でない、かわいらしいマスコット的なデザイン

【レイアウトの厳守事項】
・正方形の画像。猫の顔を中央に配置
・四隅が丸く切り取られても顔が欠けないよう、周囲に12%程度の余白を空ける
・文字・ロゴ・枠線・グリッドは一切描かない
・顔だけを大きく描く（体・足・小物は描かない）

【サイズ】
・1024×1024ピクセル
```

## クイズのかげあて用 動物 9種（`images/animals.png`／使用中）

カラーで描いてもらい、CSSの `filter: brightness(0)` で影絵にして、正解すると色を見せている。

```
同じ画風の動物を9種類、3×3のグリッドに並べた1枚のスプライトシートを作ってください。
影絵（シルエット）クイズに使うので、種類が形だけで見分けられることが最優先です。

【9マスの動物】（左上から右方向の順）
上段左：ぞう（横向き全身、鼻を下に伸ばす）
上段中央：きりん（横向き全身、首をまっすぐ上に）
上段右：うさぎ（横向き全身、耳を長く立てる）
中段左：にわとり（横向き全身、とさかをはっきり）
中段中央：さかな（横向き全身、尾びれを広げる）
中段右：かめ（横向き全身、甲羅をはっきり）
下段左：ちょう（羽を広げた真上からの形）
下段中央：うま（横向き全身、たてがみとしっぽをはっきり）
下段右：ぶた（横向き全身、丸い鼻と巻いたしっぽ）

【画風】
・フラットなベタ塗りのアニメ・絵本調、影やグラデーションは最小限
・輪郭線：こい茶色の太い線。カラーで着色する（白黒にしない）
・実物の色に近い、分かりやすい配色
・写実的でない、かわいらしいマスコット的なデザイン

【形の決まり（重要）】
・影絵にしても種類が分かるよう、その動物らしい特徴（鼻・首・耳・甲羅など）を
　輪郭の外形にはっきり出すこと
・手足や体が重ならない、開いたポーズにする
・輪郭の内側だけで表情を描き、外形をシンプルに保つ

【レイアウトの厳守事項】
・正方形の画像、3列×3行の均等な9マス（各マスも正方形）
・背景は完全な透過（PNG）。透過にできない場合は真っ白な単色背景
・グリッドの枠線・区切り線・番号・文字・ロゴは一切描かない
・各マスの中央に動物を1匹だけ配置し、マスの中で同じくらいの大きさに見えるよう
　（実物の大小は無視して）そろえる
・マスの枠に触れない、となりのマスにはみ出さない、背景に影を落とさない

【サイズ】
・1536×1536ピクセル（1マス512px）
```

## ボタンのアイコン 2種（未実装・優先度低）

濃い緑／オレンジのボタン上に置くため、白ベースで描く必要がある。

```
ボタンに使うアイコンを2種類、横1列に並べた1枚の画像を作ってください。

【2つのアイコン】
左：人の手のひらを1つ（なでる動作。手のひらを上に向けた、やわらかい形）
右：猫のごはんが入ったお皿（白いお皿に、茶色い粒のごはんが山盛り）

【画風】
・フラットなベタ塗り、影やグラデーションなし
・濃い緑色やオレンジ色のボタンの上に置くので、白とクリーム色を主体にした明るい配色
・輪郭線は白または非常に明るいクリーム色の太い線（濃い茶色の線は使わない）
・小さく表示しても分かる、単純で大きな形

【レイアウトの厳守事項】
・横2：縦1の画像を、左右の均等な2マスに分ける（各マスは正方形）
・背景は完全な透過（PNG）
・枠線・区切り線・文字は一切描かない
・各マスの中央に配置し、2つを同じ大きさにそろえ、枠に触れない

【サイズ】
・1024×512ピクセル（1マス512px）
```
