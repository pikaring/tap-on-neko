# 猫の 絵を 作りなおす プロンプト（女の子たちと 画風を そろえる 版）

> **2026-09 に この プロンプトで 8まい 作りなおし、使用中。** 生成AIは 1まいめ（お世話の 9ポーズ）に 2まいめの ポーズを まぜがちだったので、
> ちがった マスだけ「足りない ポーズを 横1列で」作って もらい、きじとらの 表の ポーズごとの 面積の わりあいで 大きさを あわせて 差しこんだ。
> そのあと 8まい いっしょに `tools/build_cat_sheet.py` に 通し（共通の 縮尺 0.9029）、マスの はしに のこった 小さな かけらを 取りのぞいた。

4柄 × 2まい ＝ **8まい** です。どれも 次の 2つを 添付して 送ります。

- `style-reference.png` … タイトル画面の 絵から 切り出した、女の子たちと 猫（**画風の 見本**）
- `now-（柄）-（1 か 2）.png` … いまの ポーズ表（**ポーズと 並び順の 見本**）

1まいめ＝お世話の ときの 9ポーズ（`cat-*.png`）、2まいめ＝ひとりで いる ときの ポーズ（`cat-*-relax.png`）。
ポーズの 位置は ゲームの 表示と 直結して いるので、並びを 変えないで ください。

8まい できたら、**全部 いっしょに** 送って ください（大きさと 立ち位置を 8まい 共通で そろえるため）。

---

## 1. きじとら・1まいめ（お世話の 9ポーズ）→ `cat-kijitora.png`

添付：`style-reference.png` と `now-kijitora-1.png`

```
同じ1匹の猫のキャラクターを、3×3のグリッドに並べた1枚のスプライトシートを作ってください。

【添付の絵について】
・「style-reference」：この作品の女の子たちと猫の絵です。猫の画風は、この絵の猫とそろえてください（線・塗り・顔立ち・体型）
・「now-kijitora-1」：いま使っている猫のポーズ表です。ポーズと並び順だけを参考にし、画風はまねしないでください

【キャラクター】
・四足の子猫。9マスすべて完全に同じ1匹（毛色・模様・体型・線の太さを統一。首輪なし）
・毛色：茶色と こげ茶の しま模様（キジトラ）。口のまわり・胸・おなか・足先は 白。目は 黄緑

【画風（厳守：添付の女の子たちと同じ作品に見えること）】
・フラットな絵本・アニメ調。女の子たちの絵と同じ線と塗り
・輪郭線：こい茶色（#3a2a20）の、太さが一定の線。女の子の輪郭線と同じ太さにする（太すぎる線・二重線にしない）
・塗り：ベタ塗り。影を入れるなら1段だけ暗い色を小さく。グラデーション・光沢・テクスチャ・ぼかしは使わない
・顔：大きめの目に白いハイライトを1つ、小さな鼻、線1本のやわらかい口。女の子たちの表情と同じ描き方
・体型：頭が少し大きい、子猫らしいやわらかいデフォルメ（頭：体＝1：1.3くらい。2頭身のマスコットにしすぎない）
・色は少し落ち着いた、やさしい色。原色やネオンのような強い色は使わない

【9マスのポーズ】（左上から右方向の順）
上段左：正面を向いておすわり、にっこり笑っている
上段中央：うれしくてジャンプ、目を細めて笑っている
上段右：足元の白いごはんのお皿に顔を寄せて食べている
中段左：前足を前に伸ばして大きくあくびをしている（朝の伸び）
中段中央：おしりを高く上げ、前足を伏せた「遊んで」の誘いポーズ
中段右：体を丸めて目を閉じ、気持ちよく眠っている
下段左：後ろ足で立ち上がり、片方の前足を上げて手を振っている
下段中央：両方の前足を上に上げてバンザイ、とても喜んでいる
下段右：首をかしげて不思議そうに考えている

【レイアウトの厳守事項】
・正方形の画像、3列×3行の均等な9マス（各マスも正方形）
・背景は真っ白な単色（#ffffff）。床・影・地面は描かない
・グリッドの枠線・区切り線・番号・文字・ロゴは一切描かない
・各マスの中央に猫を1匹。9匹すべて同じ大きさ（体の高さをそろえる）で、足もとの高さもそろえる
・マスの枠に触れないよう、まわりに10%ほどの余白。となりのマスにはみ出さない
・小物は上段右のごはんのお皿だけ

【サイズ】
・1536×1536ピクセル（1マス512px）
```

## うまく いかない とき

- **線が 太い・マスコットっぽく なる**：「女の子の輪郭線と同じ太さ」を「the outline must be as thin as the girls' outlines in style-reference; do NOT use thick sticker-like outlines」と 英語で 足す。
- **柄が 見本と ちがう**：`now-…` の 猫を 見本に した ことを もう1回 書き、毛色の 行を 最後にも くりかえす。
- **9匹の 大きさが ばらばら**：多少は `tools/build_cat_sheet.py` が そろえます。極端な ときだけ 作り直し。
- **背景が 白く ならない**：市松模様や うすい 色でも スクリプトが 抜きます。
