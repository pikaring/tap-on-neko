# ネコネソンヌ タイル絵の バリエーション用プロンプト（Gemini 用・8版目）

タイトル画像の 街を グリッドに 起こした 見本 `art/base-1.png`（3×3 の 9マス）を 基準に、**建物の 種類だけ かえた** 新しい 3×3 を どんどん 作る。できた 中から 使える マスを えらんで タイルに する。

## 方針（2026-09-30）

- 見本は **各マスが ひとつの 街区**：外周を 木立・生け垣（緑）で かこみ、中に 建物や 庭を ぎっしり。マスと マスの 間は ベージュの 地面。真上から。この 構図・絵柄・線・色を そのまま つかう
- 猫道の 線は 絵に 描かない（あとで 上書き）。線が 通る 位置は 屋根の 棟・建物の 境目・グラウンドの 真ん中などが 見立てに なる ので、**1マスの 中に 建物が ぎっしり** あって よい
- 数を 出して 選ぶ：1シート 9マス × 10種類の テーマ ＝ 90マス。使えない マスは 捨てて よい（デッキは 94まい。ダブりも 可）
- 見本の 中で **特に よい 点**（そろえる）：木立の 外周・屋根の 色わけ・道具や 看板の 絵記号（文字なし）・駐車場の 白線・野球の ダイヤモンド など、こまかい 生活感

## 共通の 文章（毎回 先頭に つける）

添付：`base-1.png`（見本）

```
添付の画像は、猫たちの陣取りボードゲーム「ネコネソンヌ」の盤になる「猫の街」のタイル見本です（3×3の9マス）。
この見本と同じ絵柄・線の太さ・色づかい・構図で、9マスの中身だけを下のものに変えて、新しい3×3の画像を作ってください。

・構図は見本と同じ：各マスは正方形で、外周に木立か生け垣（緑）をめぐらせ、その中に建物や庭をぎっしり描く。マスとマスの間はベージュの地面で、幅も見本と同じ
・完全に真上から見た地図のような絵。斜めの立体・影・台座は描かない
・文字は描かない（看板は絵記号だけ）。人・猫は描かない
・見本の建物をそのまま写さず、新しい建物・新しい配置にする。9マスとも、屋根の色・大きさ・配置を変える
・マスの中で完結させる（となりのマスに物をはみ出さない）
・正方形（1:1）で大きく（1536×1536ピクセルくらい）
```

各テーマは、この 文章の あとに 【9マスの中身】を つづけて 送る。

## 1マスだけ 作りなおす とき

うまく いかない マスが あれば、見本と そのシートを 添付して：

```
添付の「見本」と同じ絵柄・構図で、正方形（1:1）の1マスだけを作ってください。中身は「○○」。外周は木立か生け垣、真上から、文字・人・猫なし。
```

## Gemini で うまく いかない とき

- **見本の 建物を そのまま 写す**：「見本と ちがう 建物・配置に。屋根の 色も かえる」と 足す
- **斜めに なる／台座の 影が つく**：「屋根と 地面が 見える 真上からの 地図のような 図。影・台座・斜めは なし」と 足す
- **マスが またぐ／数が ちがう**：「正方形の 3×3。9マス ぴったり。マスの 間は ベージュの 地面」と 足す
- **文字が 入る**：「看板・のれんは 絵記号だけ。英語・ひらがな・漢字は 不可」と 足す
- **絵柄が 見本から ずれる**：見本を 添付しなおし「この 絵と 同じ 絵柄・線の 太さ・色で」と 足す

## できた 絵の つかいかた

- 3×3 を 切りわけて 1マスずつ 保存（`docs/cut-art.js` を この 用途に 直す）。使える マスを えらぶ
- 選んだ マスを タイルに 割りあて、猫道の 形（十字・T字・直線・角・行き止まり・道なし・魚屋）の 帯を 上に 重ねる：ゲームは 持ち主の 色の 帯（幅 16%）、印刷用は 目立つ 線（10〜12%）。どの 形にも 使えるように、マスの 辺の まん中を 通る 見立て（棟・境目・グラウンドの 真ん中）が ある マスを えらぶと よい
- 魚屋タイルは B の 魚屋を 使う
