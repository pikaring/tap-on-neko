# ほかの AI に 感想を きく ための プロンプト

下の ブロックを そのまま 貼りつけて 使う。ルールは `main.js` の 実装（2026-09-29 時点）に あわせて ある。

```
あなたは経験豊富なボードゲームデザイナーです。開発中の陣取りボードゲーム「ネコネソンヌ」のルールを読み、率直な感想と改善案をください。
デジタル版（ブラウザ）の試作がすでに動いていて、以下はその実装どおりのルールです。

■ コンセプト
・猫たちが街の中に「猫道」をのばし、猫道で囲んだ場所を自分のなわばりにする、ほのぼのした陣取りゲーム
・囲碁の「線で囲んで地を作る」と、カルカソンヌの「タイル配置」「多数派で持ち主が決まる」を合わせたもの
・プレイ人数 2〜4人。駒は4柄の猫（くろ・はちわれ・きじとら・ちゃしろ）
・今は最小限のルールで遊んでいて、ここから特殊マスや効果を足していく予定

■ コンポーネント
・盤：9×9マス（計81マス）。盤の外へは広がらない
・タイル：正方形。「猫道」が0〜4本、タイルの中心から辺の真ん中へまっすぐ伸びている
・山札 88枚（形ごとの枚数）：十字（4本）14／T字（3本）22／直線（2本・向かい合う）16／角（2本・となり合う）20／行き止まり（1本）8／道なし（0本）8
・最初に盤の中央に十字タイルを1枚置く
・猫コマ：2人なら1人12匹、3人なら10匹、4人なら8匹

■ 手番
1. 山札から1枚引く（手札は最大3枚。ゲーム開始時は2枚）
2. 手札から1枚選び、回転させて、すでに置かれたタイルの上下左右どこかに接するマスに置く
   ・となりのタイルからこのマスへ向かってきている猫道は、すべて受け止めてつなげなければならない（猫道を途中でふさいではいけない）
   ・こちらから出す猫道は、となりに猫道がなくてもよい（そこで行き止まりになるだけ）。分岐・合流は自由
   ・そのため「道なし」タイルは、どこからも猫道が向かってきていないマスにしか置けない
3. 置いたタイルに猫道があれば、その猫道の上（タイルの中心）に自分の猫を1匹置いてよい（置かなくてもよい）
・どこにも置けないときは手札を1枚捨ててよい（これも手番を使ったことになる）。パスもできる

■ なわばり（面）
・猫道は「境界線」。盤面を猫道で区切ってできる領域（面）を考える
  （実装では1マスを4つの「¼マス」に分け、猫道が横切っていないところだけつながっているとみなして領域を求めている）
・猫道だけでぐるりと囲まれた面が、なわばりの候補。盤の端に触れている面はなわばりにならない
・面の中に空きマスがなくなったら「完成」
・持ち主：その面に接している猫道の上にいる猫を数え、いちばん多い人のもの。1匹の猫は、接しているすべての面で数える（1本の猫道で両側の面を同時に守れる）
・同数なら、その面の点を同数の人がそれぞれ半分ずつもらう
・分岐や行き止まりは面を区切らない（区切るのは、ぐるりとつながった輪だけ）

■ 終了と得点
・盤が埋まる／山札と手札がすべてなくなる／全員が続けてパスする、のどれかで終了
・完成したなわばりの面積 ¼マス＝1点。完成していない面は0点
・いちばん小さいなわばりは、十字4枚が2×2に並んだときの中央の面で、¼マス4つ＝4点

■ これまでに試してわかったこと
・「猫道を1本でもつなげれば置ける」にしたら、猫道の端がすべてふさがって、道のあるタイルをどこにも置けなくなった → 今の「向かってくる猫道はすべて受け止める」に変更
・「盤の端も境界線として扱う」にしたら、ゲームの最後に外側全体が1つの巨大な面として完成し、そこを取った人がほぼ総取りした（324点中227〜309点が1つの面） → 今の「端に触れる面はなわばりにならない」に変更
・CPU（1手先だけ読む欲張りAI）同士だと、完成するなわばりは1ゲームに5〜9個で、ほとんどが最小の4点
・人間1人とCPU3人の4人戦では「なかなか面白い」という感想。ただし中央に76点の大きななわばりが1つでき、それを取った人が80点、ほかは4〜10点と大差がついた
・プレイした人の感想：
  - 盤面に対して猫が多い気がする（4人×8匹＝32匹で、81マスのうち約4割に猫が乗る）
  - 盤の端を壁（境界）として扱わないのは問題があるか？

■ 聞きたいこと
1. このルールで破綻している点や、あいまいな点はありますか
2. 盤の端の扱いについて。「端も境界にする」「端は境界にしない（今のルール）」以外に、良い落としどころはありますか（例：端に触れる面は半分の点、など）
3. 大きななわばりが1つできると総取りになり、差がつきすぎる問題への対策
4. 猫の数（盤の大きさとの釣り合い）、手札の枚数、タイルの配分の見直し案
5. 4人戦で面白くなる理由と、2人戦でも面白くするための工夫
6. 「猫らしさ」を出す特殊マスや効果のアイデア（例：段ボール・ひなた・魚屋などのお気に入りの場所、猫が勝手に動く、タコを置くと猫が逃げる など）。ただしルールがむずかしくなりすぎないもの
7. 囲碁らしい駆け引き（取る・取られる、死活）を、シンプルなまま入れる方法

それぞれ、理由と、できれば具体的な数値やルール文で答えてください。
```
