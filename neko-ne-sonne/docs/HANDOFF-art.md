## きまった 方針

1. **1まい ＝ 1マスの ふつうの 街の 絵**。外周を 木立・生け垣（緑）で かこみ、中に 建物や 庭を ぎっしり。真上から。影・台座・斜めなし。文字なし・人なし・猫なし。基準の 見本は `docs/art/base-1.png`
2. **店・家・アパートは 1マスに 3〜5軒**。神社・公園・学校・自然は 大きな 物 1つで よい
3. **魚屋だけは 別**：1マスに 1軒を 大きく（テーマ K）。手前（下半分の まん中）を 空ける（猫が すわる）。デッキに 6まい（道なし 4・行き止まり 2）
4. **猫道（なわばりの 線）は 絵に 描かない。仮想の 線**。あとから 上書き：ゲームは 持ち主の 色の 帯（幅 16%）、印刷用は 目立つ 線（幅 10〜12%）を 重ねた 画像を 書き出す。線の 位置（まん中から 辺の まん中へ）には 屋根の 棟・建物の 境目・グラウンドの 真ん中などが 見立てに なる
5. 猫道の 形：十字 8・T字 16・直線 20・角 24・行き止まり 12・道なし 8・魚屋 6（デッキ 94まい）。タイルは 回転するので 絵も 一緒に 回る
6. 3×3（9マス）ずつ Gemini で 作る（`variation-prompts.md` の 共通文 ＋ テーマ A〜K）。**使える マスを えらんで つかう**（ダブりも 可）

## 次に やること

1. テーマ A〜K の 絵が そろったら、使う マスを えらぶ（選ぶ基準：外周の 木立が ある・線が 少ない・斜めでない・文字なし・辺の まん中を 通る 見立てが ある）
2. `docs/cut-art.js` を 作りなおし：3×3 を 1マスずつ 切りわけ、`images/tile-NN.webp` に 保存
3. ゲームに 組みこむ：`main.js` の `tileSVG` / `townOf` を 新しい 絵に。**回転と いっしょに 絵も 回す**。魚屋タイルは K の 絵。猫道の 帯は 今の コード描画の まま（絵の 上に 重なる）
4. 印刷用：タイルごとに「絵 ＋ 帯」を 重ねた 画像の 書き出し（漫印堂 向け。45mm 角の とき 1マス 512px ≒ 290dpi）
5. 漫印堂に 問い合わせ：36〜94種類の 絵を 1回の 注文で 刷れるか（基本料が 種類ごとか）、塗り足し・解像度。20セット ＝ 1,880まい の 概算 約 4〜5万円台（税別・サイズ・加工しだい。種類ごとに 基本料が かかると 数十万円）
