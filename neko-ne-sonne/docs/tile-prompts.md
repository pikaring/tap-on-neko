# ネコネソンヌ タイル絵の 生成プロンプト（Gemini 用）

盤に ならべる タイルの 絵を Gemini で 作る ための プロンプトです。

## しくみ（絵と ゲームの 分担）

- **縄張りの ライン（猫道）は ゲームが 描く**（いまの まま）。置いた 人の 色で ぬった 線・ねこ・タコ・なわばりの 色は 絵の 上に 重なる
- **Gemini に 描いて もらうのは、その 下に しく「上から 見た 猫街の 街区」だけ**
  - タイルの まん中の **十字の 帯（幅 約28%）は 猫道が 通る 空き地** として あけて おく（石畳だけ）
  - 建物・木・小物は **四すみ** に 描く
  - こうすると 1まいの 絵を どの 形（十字・T字・直線・角・行き止まり・平地・魚屋）にも つかえる。ゲームは 猫道の ある 方向だけ 線を 描く
- 回転しても へんに ならない ように、**真上から・文字なし・向きの ある 影なし**
- 上に 半透明の なわばりの 色（青・緑・オレンジ・ピンク）が のり、さらに 猫道・ねこも 重なるので、**絵は 明るめ・淡めで、書きこみは 少なく・線は 少なく**
  - 1まいの 中に **物は 4つまで**（四すみに 1つずつ）。1つの 物も **大きな 形 2〜3こ**で 描き、こまかい 窓・かわら・れんが・柵・葉っぱの 1枚1枚は 描かない
  - 空き地の 石畳は **目地の 線を 引かない ベタ塗り**（線が 多いと 猫道の 線と ぶつかる）

## 作る もの（3まい）

| シート | 中身 | 添付する 画像 | できた 絵の 名前 |
| --- | --- | --- | --- |
| 1 | 街区タイル A（9まい） | `guides/style-title.jpg`・`guides/guide-ground.png`・`guides/board-sample.png` | `images/ground-a.png` |
| 2 | 街区タイル B（9まい） | おなじ | `images/ground-b.png` |
| 3 | 魚屋 6・トンネル 3 | `guides/style-title.jpg`・`guides/guide-items.png`・`guides/board-sample.png` | `images/items.png` |

- `style-title.jpg` … 猫街ろまんの タイトル画面（画風と 街の ふんいきの 見本）
- `guide-ground.png` … 街区タイルの 配置の 見本（まん中の 十字＝あける、点線の 緑＝建物を 描く ところ）
- `guide-items.png` … 魚屋・トンネルの 大きさの 見本（白い 背景の まん中に 1つ）
- `board-sample.png` … いまの 盤（この 上に 猫道・ねこ・なわばりの 色が 重なる、という 見本）

見本画像は `node docs/make-prompts.js` で 作りなおせます。

## 1. 街区タイル A → `images/ground-a.png`

添付：`style-title.jpg` `guide-ground.png` `board-sample.png`

```
猫たちの陣取りボードゲーム「ネコネソンヌ」の盤に並べる、正方形の街タイルを9種類、3×3のグリッドに並べた1枚の画像を作ってください。
タイルを並べると、上から見たかわいい「猫街」になります。

【添付の絵について】
・「style-title」：この作品のタイトル画面です。線・塗り・色づかい・街のふんいきをそろえてください
・「guide-ground」：9マスの配置の見本です。まん中の十字の帯（うすい茶色）は何も置かない空き地、点線の緑の四すみに建物や木を描きます。色はまねしないでください
・「board-sample」：いまのゲームの盤です。この絵の上に、ゲームが「色のついた猫道の線」「ねこ」「なわばりの半透明の色」を重ねます

【画風（厳守）】
・フラットな絵本・アニメ調。ベタ塗り。グラデーション・光沢・テクスチャ・ぼかしは使わない
・シンプルで、書きこみは少なめ。小さな飾り・細かい模様・たくさんの線は描かない（ミニアイコンのような、大きくて単純な形）
・輪郭線：こい茶色（#3a2a20）の、やや太めで太さが一定の線。線の本数は少なく、内側の細かい線（窓わく・かわらの目・れんがの目・板の目・葉脈）は省く

・写実的でない、かわいいミニチュアの箱庭のような街

【タイルの共通ルール（厳守）】
・完全に真上から見下ろした図（屋根と地面だけが見える地図のような図）。斜めの立体・遠近法・地平線は描かない。1マスまるごとの大きな建物も描かない
・影は描かない（ゲームでタイルを回転させるため）
・文字・看板の文字・数字・矢印・ロゴは一切描かない（「cafe」「bakery」「ゆ」のような英語や記号も不可。看板やのれんは無地の色だけ）
・各マスのまん中に、マスの幅の約28%の「十字の帯」を空けておく。帯は明るいベージュ（#e9e2c9 前後）の一色ベタ塗りで、石畳の目地・線・模様は描かない。建物・木・車・人も何も置かない（ここにゲームが猫道を描く）
・四すみの区画は、それぞれ「やわらかい色の角丸の地面（草の緑・砂色・灰色など）」の上に、**大きな物を1つだけ**置く。1つの区画に置く物は1つ（例：家1軒、木1本、テント1つ）。物はすみの区画の中で完結させ、帯の上やとなりのマスにはみ出さない
・道路・横断歩道・線路・川・塀・生け垣など、マスをまたいでつながるものは描かない（猫道はゲームが描く）
・人は描かない。猫も描かない（猫はゲームのコマとして上に重ねる）

【9マスの街区】（左上から右方向の順。どれも真上から見た図。四すみにそれぞれ物を1つだけ。書きこみは少なく）
上段左：商店街（四すみ＝赤白しまの屋根の店／野菜かごの店／黄色い屋根の店／ちょうちん1つ）
上段中央：学校（四すみ＝灰色の屋根の校舎／桜の木／砂色の校庭に鉄棒／ベンチ）
上段右：工場（四すみ＝のこぎり屋根の工場／れんがの煙突／木箱の山／ドラム缶）
中段左：住宅街（四すみ＝赤い屋根の家／青い屋根の家／植木鉢／洗濯物）
中段中央：公園（四すみ＝すべり台／丸い木／砂場／ブランコ）
中段右：神社（四すみ＝小さな社／赤い鳥居／石灯籠／大きな木）
下段左：畑（四すみ＝野菜のうね／野菜のうね／かかし／小さな小屋）　※1マスまるごとの大きな絵にしない
下段中央：空き地（四すみ＝土管／草むら／たんぽぽ／土管）
下段右：花屋（四すみ＝花バケツの並ぶ店／緑のしま屋根の店／植木／花壇）

【レイアウトの厳守事項】
・正方形の画像、3列×3行の均等な9マス（各マスも正方形）
・9マスはすきまなく並べ、各マスは端まで絵で埋める（白い余白・枠線・区切り線・番号・文字・ロゴは描かない）
・9マスとも、まん中の十字の帯の位置と幅は同じ

【サイズ】
・1536×1536ピクセル（1マス512px）。むずかしければ正方形（1:1）で
```

## Gemini で うまく いかない とき

- **3×3 に ならない・マスが ずれる**：1マスずつ 作る。「1マスずつ・正方形（1:1）・1まいに 1つの 街区」と 書き、【9マスの街区】の うち 1行だけを 入れて 送る（18まい＋小物 9まい）
- **十字の 帯に 物が のる**：「まん中の 十字の 帯には 何も 置かない。帯は 石畳だけ」を くりかえす。`guide-ground.png` を 添付しなおす
- **斜めから 見た 立体に なる**：「屋根と 地面だけが 見える 地図のような 真上からの 図」と 足す
- **文字が 入る**：「看板・のれん・のぼりには 文字を 書かず、無地の 色だけ。英語・ひらがな・記号も 不可」と 足す（前回は bakery・cafe・ゆ が 入った）
- **線が 多い・こまかい**：「書きこみを 半分に。1つの 物は 大きな 形 2〜3こだけ。内側の 細かい 線は すべて 省く。ミニアイコンのように 単純に」と 足す
- **色が こい**：「全体を 明るく、パステル寄りに。上に 半透明の 色を 重ねる」と 足す
- **道路や 線路が マスを またぐ**：「マスを またいで つながる ものは 描かない。四すみの 中で 完結させる」と 足す

## できた 絵を 入れる とき（2026-09-30 に 入れた）

- もとの 3まいは `docs/art/`（ground-a.jpg・ground-b.jpg・items.jpg）。`node docs/cut-art.js` で `images/` に 切りわける
  - 街区 → `town-00〜17.webp`（a の 9まい、b の 9まい）。魚屋 → `shop-0〜5.webp`、トンネル → `tunnel-0〜2.webp`（白い 背景は 外がわから 塗りつぶして 透明に）
- タイルごとに 絵を きめる（`main.js` の `townOf`。おなじ タイルは いつも おなじ 絵、回転しても 絵は 回さない）
  - 十字の 空き地が ない 1マス まるごとの 絵（銭湯 06・図書館 11・お寺 13・畑 15）は、道の ない 平地（ひるね猫の マス）に だけ つかう
  - ほかの 14まいは 猫道の ある タイルと 魚屋に
- 絵は 70% の 濃さで しき、その 上に なわばりの 色（58%）・猫道・ねこを 重ねる
- 作りなおすと よい マス：文字が 入った もの（A 商店街「bakery」・A 喫茶店「cafe」・A 銭湯「ゆ」）、斜めから 見た 銭湯、A と B の 右下が ほぼ 同じ 花屋
