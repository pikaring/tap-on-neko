# ネコネソンヌ タイル絵の 生成プロンプト

盤に ならべる 街タイルの 絵を 生成AIで 作るための プロンプトです。
**なわばりの ゲームなので「道路」ではなく、上から 見た 猫街の 街区（商店街・学校・工場…）** を 1マス 1区画として 描き、
その 中を **猫だけが 通る「猫道」** が とおります。**猫道が なわばりの 境界線** なので、塀や 生け垣では 区切りません。

## つながる ための しくみ

- どの タイルも **外周に 同じ 幅の 歩道**（ベージュの 石畳）。4つの 角も 歩道なので、ならべると 街区の あいだに 歩道の 格子が できる
- 猫道は **中心から 辺の まん中へ まっすぐ**、幅は マスの 約22%。となりの タイルの 猫道と 辺の まん中で つながる
- ゲームは タイルを 90度ずつ 回すので、**文字なし・向きの ある 影なし・完全な 真上から**
- 上に なわばりの 色（半透明）と 猫の コマを 重ねるので、絵は やや 明るく・淡く

## 作る もの（7まい）

| シート | 形（猫道が 抜ける 辺） | 使う タイル | ガイド | できた 絵の 名前 |
| --- | --- | --- | --- | --- |
| 十字 | 上・右・下・左 | 14まい | `guides/guide-cross.png` | `images/tiles-cross.png` |
| T字 | 上・右・下 | 22まい | `guides/guide-t.png` | `images/tiles-t.png` |
| 直線 | 上・下 | 16まい | `guides/guide-straight.png` | `images/tiles-straight.png` |
| 角 | 上・右 | 20まい | `guides/guide-corner.png` | `images/tiles-corner.png` |
| 行き止まり | 上 | 8まい | `guides/guide-dead.png` | `images/tiles-dead.png` |
| 道なし | なし | 8まい | `guides/guide-none.png` | `images/tiles-none.png` |
| お気に入りの 場所（あとで 足す 特殊マス用） | 列ごとに T字・角・行き止まり | いまは 使わない | `guides/guide-facility.png` | `images/tiles-facility.png` |

どれも 次の 2つを 添付して 送ります。

- `style-reference.png` … 猫街ろまんの タイトル画面から 切り出した 絵（画風の 見本。`docs/cat-sprite-prompt-v2.md` と 同じ もの）
- `guides/guide-（形）.png` … 9マスの 猫道の 位置の 見本（このフォルダに 入って います）

形は ゲームの データ（`main.js` の `DECK_DEF`）と おなじ 向きで 描いて もらいます（回転は ゲームが やる）。
9つの 街区は どの シートでも 同じ 順番なので、あとで「商店街だけ 描きなおす」も できます。

## 1. 十字 → `images/tiles-cross.png`

添付：`style-reference.png` と `guides/guide-cross.png`

```
猫たちの陣取りボードゲーム「ネコネソンヌ」の、盤に並べる正方形の街タイルを9種類、3×3のグリッドに並べた1枚の画像を作ってください。
タイルを並べていくと、上から見た かわいい「猫街」が1つにつながって完成します。
このシートは、9マスすべて「十字」の形のタイルです。

【添付の絵について】
・「style-reference」：この作品の絵です。線・塗り・色づかいをそろえてください
・「guide-cross」：9マスの猫道（うすい茶色）の位置の見本です。位置だけを守り、色や絵柄はまねしないでください

【画風（厳守：添付の「style-reference」と同じ作品に見えること）】
・フラットな絵本・アニメ調。ベタ塗り。グラデーション・光沢・テクスチャ・ぼかしは使わない
・輪郭線：こい茶色（#3a2a20）の、太さが一定の線（太すぎない・二重線にしない）
・色は少し落ち着いた、やさしい色（クリーム・木の茶・赤い屋根・若草色・水色）。原色やネオンは使わない
・写実的でない、かわいらしいミニチュアの町（おもちゃの箱庭のような雰囲気）
・この上に色つきの半透明の「なわばりの色」と猫のコマを重ねるので、全体はやや明るめ・淡めにし、細かく描きこみすぎない

【タイルの共通ルール（厳守：となりのタイルと ぴったりつながるため）】
・真上から見下ろした図（完全な俯瞰）。斜めから見た立体・遠近法・地平線は描かない
・影は描かないか、真下にごく小さく（ゲームでタイルを90度ずつ回転させるため、向きのある影は不可）
・文字・看板の文字・数字・矢印は一切描かない（回転しても変に見えないように）
・1マス＝1つの街区（ブロック）。マスの外周には、どのタイルも同じ幅（マスの約6%）の「歩道」の帯を描く。歩道は明るいベージュの石畳（#e8dcc4）で、4つの角も必ずこの歩道にする
・「猫道（ねこみち）」：猫だけが通る、細い土と飛び石の小道（色は #c9a878 前後）。幅はマスの約22%
・猫道はマスの中心から、下に書いた「抜ける辺」のちょうど真ん中へまっすぐ伸び、歩道をこえて辺まで届く（となりのタイルの猫道と、辺の真ん中でつながる）
・猫道が来ない辺には塀や生け垣を描かない（このゲームでは猫道そのものが なわばりの境界線。塀があると境界に見えてしまう）
・建物・木・小物は、猫道と歩道をよけて、猫道で区切られた区画の中に置く。猫道の上には物を置かない
・人は描かない。猫も描かない（猫はゲームのコマとして上に重ねる）

【このシートの形：十字】
・猫道が抜ける辺：上・右・下・左（その辺のちょうど真ん中）
・猫道が来ない辺：なし

【9マスの街区】（左上から右方向の順。どれも真上から見た図）
上段左：商店街（アーケードの赤と白のしま模様の屋根、八百屋の野菜かご、パン屋の店先。ちょうちんが並ぶ）
上段中央：学校（校庭の白いトラックの一部、校舎の灰色の屋根、桜の木が2本、鉄棒）
上段右：工場（のこぎり形の屋根、れんがの煙突（煙はうすく少し）、ドラム缶、積まれた木箱）
中段左：住宅街（瓦屋根の小さな家が2〜3軒、庭の植木鉢、物干しの洗濯物）
中段中央：公園（すべり台、砂場、ブランコ、丸い木が3本、ベンチ）
中段右：神社（赤い鳥居、小さな社の屋根、石灯籠、大きなご神木）
下段左：銭湯（青いのれんが見える建物、高いれんがの煙突、おけが積まれた裏口）
下段中央：空き地（土管が3本（三角に積む）、草むら、たんぽぽ）
下段右：喫茶店と花屋の角（赤い日よけの喫茶店のテラス席、花屋の店先の花バケツ）

【レイアウトの厳守事項】
・正方形の画像、3列×3行の均等な9マス（各マスも正方形）
・9マスは すきまなく ぴったり並べ、各マスは端まで絵で埋める（白い余白・枠線・区切り線・番号・文字・ロゴは描かない）
・9マスとも、猫道が抜ける辺は まったく同じにする（添付の「guide」と同じ位置。guide の色はまねしない）
・となりのマスに絵がはみ出さない

【サイズ】
・1536×1536ピクセル（1マス512px）
```

## うまく いかない とき

- **猫道の 位置が ずれる**：「guide と 同じ 位置に。猫道は マスの 中心から 辺の ちょうど 真ん中へ、幅は マスの 約22%」と 1文 足して 作りなおす
- **斜めから 見た 立体に なる**：「真上から 見下ろした 地図のような 図。建物は 屋根だけが 見える」と 足す
- **9マスで 猫道の 形が ばらばら**：1マスずつ（1024×1024、1まい 1街区）で 作って もらい、あとで ならべる
- **文字が 入る**：「看板・のれん・のぼりには 文字を 書かず、無地の 色だけ」と 足す
- **マスの さかいめに 白い すきまや 線が 入る**：「9マスは すきまなく、各マスは 端まで 絵で うめる」を くりかえす
- **猫道の ない 辺に 塀が 入る**：「猫道が 来ない 辺には 塀・生け垣・フェンスを 描かない」と 足す
