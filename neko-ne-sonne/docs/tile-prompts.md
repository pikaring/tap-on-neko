# ネコネソンヌ タイル絵の 生成プロンプト（Gemini 用・5版目）

盤に ならべる タイルの 絵を Gemini で 作る ための プロンプトです。

## 5版目の 方針（2026-09-30）

4版目は 指示が 多すぎて AI が 理解 できなかった ので、**3×3（9マス）ずつ、短い 指示で 作る**（9まいで 81マス）。

- 街の 区画わりは 9×9（下の 表）。同じ 種類の マスが ならぶと 自然に ひと続きの 場所に 見える
- **猫道の ライン用の 空き地は、太い 帯では なく「物と 物の すき間」くらい**（マス幅の 約8%、まん中を 十字に）。猫道の 帯は 絵に 描かず、仕上げに 重ねる：
  - **ブラウザ**：ゲームが 上から 帯（持ち主の 色・幅 16%）を 重ねるので、絵の すき間の 太さは 関係ない
  - **アナログ（印刷）**：この すき間に 目立つ 線が 入る。帯の 幅は 10〜12% くらいに して 書き出す
- 物は 1マスの 中で 完結（となりの マスに またがらない）。これで マスを 入れかえても 街に なる
- 絵は 明るめ・淡めで、書きこみは 少なく、文字・影・斜めの 絵は なし（タイルを 回す ため）

## 漫印堂で 印刷する とき（メモ）

[ゲームチップ（タイル）の ページ](https://www.mnd.co.jp/pricelists/chips/) より：

- 形：**正方形 15〜45mm**（角丸 正方形 14mm〜63×88mm・丸・六角形・ドミノも ある）。厚さ 約2mm の 紙。表と 裏で ちがう 絵に できる（追加 料金なし）
- 基本料 2.3〜3.5万円 ＋ 1まいあたり 数円〜数十円（サイズ・加工で かわる）。**1,000セット以上は オフセット印刷** の 可能性
- AI・PSD の テンプレートが ページから ダウンロード できる（ページに 解像度・塗り足しの 記載は なし。注文する とき 問い合わせる）
- 絵は **マスの はしまで ぜんぶ 塗る**（塗り足しの 分だけ 少し はみ出す 前提）。角丸の 場合は 四すみの 角に 大事な 物を 置かない
- 45mm 角なら 1マス 512px で 約 290dpi。もう 少し 細かく したい ときは 1024px で 作りなおす

**きめる こと**（あとで 相談）：
1. サイズと 形（例：40mm 角・角丸）
2. 種類ごとの 枚数（デッキ 94まい ＝ 十字 8・T字 16・直線 20・角 24・行き止まり 12・道なし 8・魚屋 6）を、絵を 何種類 つくって 何まいずつ 刷るか。**同じ 絵を 何まいも 刷る ほうが 版が 少なくて 安い** 可能性（下の 36種 なら、1種 2〜3まい）
3. 裏面：ねこの あしあと 柄などの 共通の 絵
4. ねこの コマ：いまの ルールは「猫道の ある タイルには かならず ねこが のる」ので、4色 ×（1人 20〜25匹）の コマが 要る。同じ チップで 「ねこ チップ」を 作るのが 手軽

## デッキ（94まい）と 絵の わりあて

- 街の 絵は **81マス**。デッキは 94まいなので、**81まい ＋ 13まい（ダブり）**
- 1まいの チップ ＝ 「街の 1マスの 絵」＋「猫道の 形（十字 8・T字 16・直線 20・角 24・行き止まり 12・道なし 8・魚屋 6）の 帯」
- わりあての 目安：**魚屋の 6マスは 魚屋タイル**、**道なし 8まいは 平地に 向く マス**（空き地・森・畑・池・公園）、のこりは どこにでも
- 帯は すき間の 十字に 重なる ので、どの 形を のせても 大きくは ぶつからない

## 作る もの（9まい ＝ 3×3 ブロック）

| 手順 | 添付する 画像 |
| --- | --- |
| ブロック 1 | `style-title.jpg`・`guide-lane.png` |
| ブロック 2〜9 | 上 ＋ **できた `block-1.jpg`（絵柄を そろえる）** |

- `style-title.jpg` … 猫街ろまんの タイトル画面（画風の 見本）
- `guide-lane.png` … 3×3 の 見本。**すき間の 位置と 細さ**の 見本（色は まねしない）。見本は `node docs/make-prompts.js tiles` で 作りなおせる
- ブロック 1 の 絵柄が 決まってから 2〜9 を 作る。絵柄が ずれたら ブロック 1 を 添付しなおす
- 1つの ブロックは 1536×1536px（1マス 512px）。45mm 角で 約 290dpi

トンネル（盤の 上下の ふちの 穴）は 2版目の 絵（`art/items.jpg` の 下段）を そのまま つかう。

## 共通の 文章（各ブロックの 先頭に つける）

```
猫たちの陣取りボードゲームの盤になる「猫の街」を、真上から見下ろした絵で作ってください。
正方形の画像を3×3の9マスに分け、各マスの中に、街の一部（建物や庭など）を描きます。

・添付の「style-title」の絵柄と色づかいにそろえてください
・添付の「guide-lane」のように、各マスのまん中を細いベージュの通路が十字に通ります。物どうしのすき間はこの細さ（マスの幅の約8%）にしてください。通路の上には何も置かない
・1マスの中に、大きくて単純な建物や庭を2〜4個。物はそのマスの外にはみ出さない（となりのマスにまたがらない）
・真上から見た地図のような絵。斜めの立体・影は描かない
・やさしいパステル色のベタ塗り。線はこい茶色でやや太く、少なめ。窓・かわらの目・柵などの細かい飾りは描かない
・文字・看板の文字・人・猫は描かない。九マスの枠線や区切り線は描かない
・正方形（1:1）で大きく（1536×1536ピクセルくらい）
```

各ブロックは、この 文章の あとに 【9マスの中身】を つづけて 送る。

## Gemini で うまく いかない とき

- **すき間が 太い／十字に ならない**：「物どうしの すき間は 細く（マスの幅の 8%）。まん中を 十字に とおる。見本と 同じ」と 足す
- **マスを またぐ 物を 描く**：「1マスの 中で 完結。となりに またがらない」と 足す
- **9マスに 分かれない・数が ちがう**：1マスずつ 作る（「正方形 1:1・1マスぶんの 絵」と 書き、その マスの 中身だけ 入れる）
- **絵柄が ブロックごとに ばらばら**：ブロック 1 を 添付して「この絵と 同じ 絵柄・線の 太さ・色で」と 足す
- **線が 多い・こまかい**：「書きこみを 半分に。1つの 物は 大きな 形 2〜3こだけ。内側の 細かい 線は 省く。ミニアイコンのように 単純に」と 足す
- **斜めから 見た 立体に なる**：「屋根と 地面だけが 見える 地図のような 真上からの 図」と 足す
- **文字が 入る**：「看板・のれん・のぼりには 文字を 書かず、無地の 色だけ。英語・ひらがな・記号も 不可」と 足す
- **色が こい**：「全体を 明るく、パステル寄りに」と 足す

## できた 絵を 入れる とき

`block-1〜9.jpg` が できたら 送って ください。

- 9まいを つなげて 81マスに 切りわけ、**タイルごとに 1マスの 絵**を 割りあてる（`docs/cut-art.js` を 5版目用に 直す）
- 絵は 回さず、猫道の 帯（持ち主の 色）を 上に 重ねる。すき間が まん中の 十字なので、どの 向きでも つながって 見える
- 魚屋タイルは 魚屋の マスの 絵を 使い、ねこは 店先（下半分の まん中）に すわる
- 印刷用：タイルごとに「絵 ＋ 猫道の 帯（幅 10〜12%）」を 重ねた 画像を 書き出す（帯は 辺の まん中へ ぴったり）
