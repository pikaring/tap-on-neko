# ネコネソンヌ タイル絵の 生成プロンプト（Gemini 用・6版目）

盤に ならべる タイルの 絵を Gemini で 作る ための プロンプトです。

## 6版目の 方針（2026-09-30）

**1まいの タイル ＝ 1マスの 絵。物（建物・庭）を 大きく 置き、物と 物の すき間が そのまま 猫道の 形に なる。** すべて 1マスの 中で 完結する。

- タイルの 形は 6種。形ごとの 物の 並べ方（灰色＝物、白＝すき間）は 見本画像（`guides/guide-*.png`）どおり：
  - 十字：四すみに 物 4つ　／　T字（⊥）：上に 2つ・下に 横長 1つ　／　直線：左右に 縦長 1つずつ
  - 角（┐）：L字の 大きな 物 1つ ＋ 左下に 小さな 1つ　／　行き止まり：1つの 大きな 物に 下から まん中まで の 切れこみ
  - 道なし：1マス いっぱいの 物 1つ
- **すき間の 幅は マスの 約10%**、ふちの 余白は 約3%。すき間は マスの 辺の まん中に 出る（となりの タイルと つながる）
- 猫道の 帯は 絵に 描かない。仕上げに 重ねる：
  - **ブラウザ**：ゲームが 上から 帯（持ち主の 色・幅 16%）を 重ねるので、すき間の 細さは 関係ない
  - **アナログ（印刷）**：この すき間に 目立つ 線が 入る。帯の 幅は 10〜12% くらいに して 書き出す
- **3×3（9マス）ずつ、同じ 形で 9種類** を 1シートに 出す（1シート ＝ 1つの 形。AI が 理解しやすい）。10シートで 90種類
- 場所（商店・住宅・森 など）は マスごとに 変える。同じ 場所の 物が ならぶと ひと続きの 街に 見える
- 絵は 明るめ・淡めで、書きこみは 少なく、文字・影・斜めの 絵は なし（タイルを 回す ため）

## 漫印堂で 印刷する とき（メモ）

[ゲームチップ（タイル）の ページ](https://www.mnd.co.jp/pricelists/chips/) より：

- 形：**正方形 15〜45mm**（角丸 正方形 14mm〜63×88mm・丸・六角形・ドミノも ある）。厚さ 約2mm の 紙。表と 裏で ちがう 絵に できる（追加 料金なし）
- 基本料 2.3〜3.5万円 ＋ 1まいあたり 数円〜数十円（サイズ・加工で かわる）。**1,000セット以上は オフセット印刷** の 可能性
- AI・PSD の テンプレートが ページから ダウンロード できる（ページに 解像度・塗り足しの 記載は なし。注文する とき 問い合わせる）
- 絵は **マスの はしまで ぜんぶ 塗る**（塗り足しの 分だけ 少し はみ出す 前提）。角丸の 場合は 四すみの 角に 大事な 物を 置かない
- 45mm 角なら 1マス 512px で 約 290dpi。もう 少し 細かく したい ときは 1024px で 作りなおす

**きめる こと**（あとで 相談）：
1. サイズと 形（例：40mm 角・角丸）
2. 種類ごとの 枚数（デッキ 94まい ＝ 十字 8・T字 16・直線 20・角 24・行き止まり 12・道なし 8・魚屋 6）を、絵を 何種類 つくって 何まいずつ 刷るか。**同じ 絵を 何まいも 刷る ほうが 版が 少なくて 安い** 可能性（下の 36種 なら、1種 2〜3まい）
3. 裏面：ねこの あしあと 柄などの 共通の 絵
4. ねこの コマ：いまの ルールは「猫道の ある タイルには かならず ねこが のる」ので、4色 ×（1人 20〜25匹）の コマが 要る。同じ チップで 「ねこ チップ」を 作るのが 手軽

```
猫たちの陣取りボードゲームの盤になる「猫の街」のタイルを、9枚（3×3）並べた1枚の画像で作ってください。
9枚とも同じ形の配置で、添付の「guide」のとおりです。灰色の四角が建物や庭などの「物」、白いすき間が猫の通り道です。

・9枚それぞれに、【9マスの中身】の場所を描く。物の位置と大きさ、すき間の位置と細さ（マスの幅の約10%）は、見本と同じにする
・すき間は何も置かず、ベージュ（#e9e2c9）の地面だけにする。すき間は見本のとおり、マスの辺のまん中まで届かせる
・物はマスの外にはみ出さない。各マスは端まで絵で埋める
・添付の「style-title」の絵柄と色づかいにそろえる。真上から見た地図のような絵で、斜めの立体・影は描かない
・やさしいパステル色のベタ塗り。線はこい茶色でやや太く、少なめ。窓・かわらの目・柵などの細かい飾りは描かない
・文字・看板の文字・人・猫は描かない。マスの枠線や区切り線は描かない
・正方形（1:1）で大きく（1536×1536ピクセルくらい）
```

## Gemini で うまく いかない とき

- **すき間が 見本と ちがう／太い**：「物の 配置と すき間の 位置・細さは 見本と 同じ。すき間は マス幅の 10%」と 足す。見本が 伝わらない ときは 1マスぶんの 見本（`guide-*.png` を 1マスに 切った もの）を 添付して 1マスずつ 作る
- **物が マスを またぐ**：「1マスの 中で 完結。となりに またがらない」と 足す
- **9マスに 分かれない・数が ちがう**：「正方形の 3×3。9枚 ぴったり」と 足す。だめなら 1マスずつ
- **絵柄が シートごとに ばらばら**：シート1 を 添付して「この絵と 同じ 絵柄・線の 太さ・色で」と 足す
- **線が 多い・こまかい**：「書きこみを 半分に。1つの 物は 大きな 形 2〜3こだけ。内側の 細かい 線は 省く。ミニアイコンのように 単純に」と 足す
- **斜めから 見た 立体に なる**：「屋根と 地面だけが 見える 地図のような 真上からの 図」と 足す
- **文字が 入る**：「看板・のれん・のぼりには 文字を 書かず、無地の 色だけ。英語・ひらがな・記号も 不可」と 足す
- **色が こい**：「全体を 明るく、パステル寄りに」と 足す
