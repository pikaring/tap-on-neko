# ネコネソンヌ タイル絵の 生成プロンプト（Gemini 用・4版目）

盤に ならべる タイルの 絵を Gemini で 作る ための プロンプトです。

## 4版目の 方針（2026-09-30）

3版目（1マスごとに 場所を えがく）を ためしたら「ならべても 街に 見えない」ので、**まず 9×9 の 街の 完成図を 1まい 作り、それを 切りわけて タイルに する**。

- **街の 完成図 ＝ 猫街ろまんの 骨格**：商店街を まん中に、まわりに 住宅・アパート、はしに 森・畑・公園・学校・神社・野球場・工場…が ならぶ 9×9 の 街
- **どの マスも 十字の 空き地（幅 約28%）を あけ、四すみに 物を 置く**：マスを 入れかえても、十字が つながる 格子の 街に なる（となりの 空き地の 位置が いつも 同じ ため）
- **物は マスの ふちから 少し はなす**（となりの マスの 物と くっつかない）。地面の 色は ふちまで ぬって よい（同じ 場所が 続けば つながって 見える）
- **文字・向きの ある 影・斜めの 絵は なし**（タイルを 回すので）
- **縄張りの ライン（猫道）は 絵に 描かない**。仕上げに コードで 重ねる：ゲームでは 持ち主の 色の 帯、印刷用には **タイルの 形ごとに 同じ 帯を ぴったり 重ねた 画像を 書き出す**（ずれない ように 生成AIには 描かせない）
- 絵は 明るめ・淡めで、書きこみは 少なく（前の 版の 反省）：1つの 物は 大きな 形 2〜3こ、線は 少なく、ベタ塗り

## 漫印堂で 印刷する とき（メモ）

[ゲームチップ（タイル）の ページ](https://www.mnd.co.jp/pricelists/chips/) より：

- 形：**正方形 15〜45mm**（角丸 正方形 14mm〜63×88mm・丸・六角形・ドミノも ある）。厚さ 約2mm の 紙。表と 裏で ちがう 絵に できる（追加 料金なし）
- 基本料 2.3〜3.5万円 ＋ 1まいあたり 数円〜数十円（サイズ・加工で かわる）。**1,000セット以上は オフセット印刷** の 可能性
- AI・PSD の テンプレートが ページから ダウンロード できる（ページに 解像度・塗り足しの 記載は なし。注文する とき 問い合わせる）
- 絵は **マスの はしまで ぜんぶ 塗る**（塗り足しの 分だけ 少し はみ出す 前提）。角丸の 場合は 四すみの 角に 大事な 物を 置かない
- 45mm 角なら 1マス 512px で 約 290dpi。もう 少し 細かく したい ときは 1024px で 作りなおす

**きめる こと**（あとで 相談）：
1. サイズと 形（例：40mm 角・角丸）
2. 種類ごとの 枚数（デッキ 94まい ＝ 十字 8・T字 16・直線 20・角 24・行き止まり 12・道なし 8・魚屋 6）を、絵を 何種類 つくって 何まいずつ 刷るか。**同じ 絵を 何まいも 刷る ほうが 版が 少なくて 安い** 可能性（下の 36種 なら、1種 2〜3まい）
3. 裏面：ねこの あしあと 柄などの 共通の 絵
4. ねこの コマ：いまの ルールは「猫道の ある タイルには かならず ねこが のる」ので、4色 ×（1人 20〜25匹）の コマが 要る。同じ チップで 「ねこ チップ」を 作るのが 手軽

## デッキ（94まい）と 絵の わりあて

- 街の 絵は **81マス**。デッキは 94まいなので、**81まい ＋ 13まい（ダブり）**
- 1まいの チップ ＝ 「街の 1マスの 絵」＋「猫道の 形（十字 8・T字 16・直線 20・角 24・行き止まり 12・道なし 8・魚屋 6）の 帯」
- わりあての 目安：**魚屋の 6マスは 魚屋タイル**、**道なし 8まいは 平地に 向く マス**（空き地・森・畑・池・公園）、のこりは 街の どこにでも。おなじ 絵に ちがう 形を のせても よい（回すので 絵の 見え方が かわる）
- 猫道の 帯と 絵の 十字の 空き地は 同じ 位置・幅なので、どの 形を のせても ぶつからない

## 街の 区画わり（9×9・1文字＝1マス）

```
森森畑畑畑神神森森
森住住住ア神神公公
住住ア商商商商公野
住ア商魚商魚商公野
空商魚商商商魚学野
住ア商魚商魚商学学
住住ア商商商商学空
工住住ア図銭空空森
工工畑畑池森森森森
```

森・畑・神社・公園・学校・野球場・空き地・工場・銭湯・図書館・池 と 商店・魚屋・住宅・アパート の 15種。

- **商店**：四すみに、赤白しまの日よけの店・野菜かごの八百屋・パン屋の店先・花屋・駄菓子屋・喫茶店・郵便局・猫カフェの屋根から、ちがう店を4つ（屋根は無地の色。看板の文字なし）
- **魚屋**：魚屋。しま模様の日よけの屋台を上よりに1つ大きく（魚は3匹まで）。手前（下半分のまん中）は空けておく（猫がすわる）
- **住宅**：四すみに、赤・青・茶の瓦屋根の小さな家、植木鉢、物干し（洗濯物）、庭木から4つ
- **アパート**：四すみに、平らな屋根のアパート（屋上の給水タンク、ベランダの植木鉢、洗濯物）から4つ
- **森**：四すみに、丸い大きな木の茂み。切り株・きのこ・草むらを少し。地面は濃い緑
- **畑**：四すみに、野菜のうね・小さな田んぼ・かかし・小さな小屋から4つ。地面は黄緑と土の色
- **神社**：四すみに、小さな社・赤い鳥居・石灯籠・ご神木から4つ。地面は白っぽい玉砂利
- **公園**：四すみに、すべり台・ブランコ・砂場・ベンチと丸い木から4つ。地面は明るい緑と砂色
- **学校**：四すみに、灰色の屋根の校舎・校庭の鉄棒・桜の木・時計台から4つ
- **野球場**：四すみに、ホームベースのある小さな野球のダイヤモンド・バックネット・ベンチ・ナイター照明から4つ。地面は明るい緑と土の色
- **工場**：四すみに、のこぎり屋根の工場・れんがの煙突・木箱の山・ドラム缶から4つ。地面は灰色
- **空き地**：四すみに、土管・草むら・たんぽぽ・積んだ資材から4つ。地面は砂色
- **図書館**：四すみに、屋根の建物・中庭の木・ベンチ・花壇から4つ
- **銭湯**：四すみに、無地の青いのれんの建物の屋根（文字なし）・高いれんがの煙突・おけ・薪の山から4つ
- **池の庭**：四すみに、小さな池・飛び石・もみじの木・植え込みから4つ

## Gemini で うまく いかない とき

- **十字の 空き地に 物が のる／十字が ずれる**：「まん中の 十字の 空き地は ベージュの ベタ塗りだけ。物は 置かない。位置と 太さは 見本と 同じ」を くりかえす
- **完成図が 街に 見えない／マスごとに ばらばら**：「同じ 種類の マスが ならぶと ひと続きの 場所に 見える ように、地面の 色・屋根の 色を そろえる」を 足す。区画わりの 見本（guide-town）を 添付しなおす
- **マスを またぐ 物を 描く**：「マスを またぐ 物は 描かない。1マスの 中で 完結」と 足す
- **線が 多い・こまかい**：「書きこみを 半分に。1つの 物は 大きな 形 2〜3こだけ。内側の 細かい 線は すべて 省く。ミニアイコンのように 単純に」と 足す
- **斜めから 見た 立体に なる**：「屋根と 地面だけが 見える 地図のような 真上からの 図」と 足す
- **文字が 入る**：「看板・のれん・のぼりには 文字を 書かず、無地の 色だけ。英語・ひらがな・記号も 不可」と 足す
- **色が こい**：「全体を 明るく、パステル寄りに。上に 半透明の 色を 重ねる」と 足す
- **ブロックが 完成図と ちがう**：完成図の その 範囲を 切りぬいた 画像を 追加で 添付して「この 絵を そのまま 高精細に」と 言う
