# ネコネソンヌ（neko-ne-sonne）試作

**猫道を のばして つなげ、ぐるりと かこんだ 面を なわばりに する** 陣取り ゲーム。
囲碁の「線で かこむ」と、タイル配置の「多数派」を あわせた 形です。猫街ろまん（tap-on-neko）の 4柄の ねこが 駒。

このフォルダは 画像も ふくめて **これだけで 動きます**（HTML / CSS / Vanilla JavaScript、通信・保存なし）。
専用リポジトリ `neko-ne-sonne` を つくったら、フォルダの 中身を そのまま うつせば OK です
（左上の「‹ 猫街ろまん」リンク `../app/` だけ 書きかえてください）。

まずは シンプルな 形で あそび、そこから 特殊マスや 効果（施設・浸食・ボス猫 など）を 足して いく 予定です。

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の 入口 |
| `main.js` | ルール（盤・面の 計算・得点）と CPU と 描画。ルールの 関数は 描画と わけて ある |
| `style.css` | 見た目（猫街ろまんと 同じ 配色） |
| `images/cat-*.png` | 4柄の ねこ（3×3 スプライト。tap-on-neko から コピー） |
| `docs/tile-prompts.md` | 街タイルの 絵（上から 見た 猫街の 街区＋猫道）の 生成プロンプト |
| `docs/guides/guide-*.png` | プロンプトに 添付する、猫道の 位置の 見本（ゲームの データから 作成） |

## ルール（2026-09-29 版）

猫道で えがく 囲碁。**ねこは 無限** で、おいた 猫道は かならず 自分の 色に なります（タイル＝囲碁の 石）。
（猫の 数に 限りが ある「猫街モード」も ためしたが、点の 計算が めんどうなので はずした）

### じゅんび
| 人数 | 盤 | タイル |
| --- | --- | --- |
| 2人 | 7×7 | 場に 4まい ならんだ 共通の タイルから えらぶ |
| 3人 | 9×9 | 手札 3まいまで（はじめは 2まい） |
| 4人 | 9×9 | 手札 3まいまで（はじめは 2まい） |

- まん中に 十字の タイルを おいて はじめる。
- デッキ 94まい：十字 8・T字 16・直線 20・角 24・行き止まり 12・道なし 8・魚屋 6（道なし 4・行き止まり 2）。

### おく
- タイルを 1まい えらんで、すでに ある タイルの となりに おく（回転 自由）。
- **となりの タイルとの 辺は ぴったり あわせる**（道が 辺まで 出て いたら かならず 道どうしで つなぐ）。盤の 端へ 出る 猫道は よい。
- 猫道（か 魚屋）の ある タイルには、**かならず おいた 人の ねこが のり**、猫道が その 人の 色に なる。
- おける ときは かならず おく。どの タイルも おけない ときは、おける ものが 出るまで 1まいずつ すてて 引きなおす（自動）。山札が なければ パス。

### なわばり
- **猫道と 盤の 端が 境界線**。かこまれた 面が なわばりの 候補。
- ただし **上と 下の 辺の まん中は トンネル**。トンネルを ふくむ 面は 0点（はじめは 四辺に あったが、縛りが 大きいので 上下 2つに。外がわ ぜんたいの 面は 上下の 辺に かならず ふれるので 総取りは ふせげる）。
- 面の 中に 空きマスが なくなったら 完成し、**すぐ 採点**：
  - その 面に 面した ねこ（と タコ）が いちばん 多い 人が、**面が かかった タイル 1まいにつき 1点**（¼・½・¾だけ かかって いても 1点）。同じ ねこは 同じ 面では 1票。
    - いちばん 小さい なわばり（十字 4まいの まん中）は 4点。まえの「¼マス＝1点」に くらべ、広い なわばりは およそ 4分の1 に なる（魚屋・タコ・とった ねこと つりあう ように）。
  - 同数なら **セキ**（囲碁と おなじ）：だれの ものでも なく 0点、ねこも とらない。
    - 山分け（人数で わって 切りすて）は アナログで 計算が めんどう。「閉じた 人の 勝ち」は 4人戦で 関係ない 人が 閉じる ことが あるので やめた。
  - 持ち主は 境界の **相手の ねこを とる**（盤から のぞく、1匹 1点）。とられた 猫道は だれの 色でも なくなり、となりの 面でも 票に ならない。自分の ねこは のこる。

### 🐟 魚屋（カルカソンヌの 修道院の ような マス）
- 山札に 6まい：道なしの 平地 4・行き止まりの 道つき 2（平地と 行き止まりに 役わりを もたせる）。おいた 人の ねこが のる。
- まわりの 盤内の マスが ぜんぶ うまったら 完成し、すぐ 採点：**まわり 3×3（魚屋も ふくむ）で ねこが いちばん 多い 人**（タコは 2匹ぶん）が **5点**。同数なら **魚屋に のって いる ねこ（か タコ）の 持ち主** の 勝ち（その 人が 同数に いなければ だれの ものでも なく 0点）（はじめは まわりの マス数 9・6・4点 だったが、たかすぎたので 5点に）。
  - CPU どうし（10局ずつ）：魚屋 5点で 点の 18〜19%、3点で 10〜11%。どちらも 魚屋の 点で 1位が 入れかわる 試合は 0〜2/10
  - 盤は ほぼ ぜんぶ うまるので、カルカソンヌの 修道院と ちがって 完成は ほぼ 確実。「引いて おくだけで 9点」に ならない ように、まわりの 多数派の ものに した。
- **魚屋の ねこは 完成後も そのまま のこる**。完成しないまま おわったら 0点。
- 行き止まりの 道つきの 魚屋の ねこは、ふつうの ねこと おなじく なわばりの 票にも なり、とられる ことも ある。
- 未完成の 魚屋が あるうちは、ゲームは おわらない。

### 💤 平地の ひるね猫
- 道の ない 平地の タイルにも、おいた 人の ねこが のる（ひるね猫）。なわばりの 票には ならない。魚屋の まわり 3×3 では 1匹と 数える。
- ひるね猫の いる 面が **相手の なわばりとして 完成したら、その ひるね猫は とられる**（相手に 1点）。
- **ゲームの さいごまで** なわばりの 外（トンネルに つながった 面・未完成の 面）で ねて いた ひるね猫は **1匹 3点**。
- ためした けいい（CPU どうし）：
  - 「野良地を ひるね猫の 多数派が タイル 1まい 1点」→ ひるね猫 1〜3匹で 40〜70点。1位が 入れかわった 試合 9/22（つよすぎ）
  - 「なわばりの 外なら 1匹 5点・とられない」→ リスクなしで 5点 入るのが つよい
  - 「のまれたら とられる・外なら 1匹 3点」（いま）→ 点の 7〜13%、1位が 入れかわる 試合 0〜2/10

### 🐙 タコ（1人 1回）
- 「🐙 タコ」を えらんで、次の どちらかで 出す：
  1. **手札の タイルを おく とき、その 上に タコを のせて 出す**（ねこの かわりに タコ。タイルを おく 手番の まま なので 1手 損しない）
  2. タイルを おく かわりに、**盤の 上の 自分の ねこ 1匹を タコと 交換**（自分の ねこが いる マスに だけ。相手の 魚屋などは うばえない）
- 上下左右の **猫道に いる 相手の ねこ だけ** が 持ち主の 手もとへ 逃げる（だれの 点にも ならない）。
- 自分の ねこ・**魚屋の ねこ**（完成前も）・完成した なわばりの 境界の ねこは 逃げない。
- その 5マスには、あとから おかれた タイルにも ねこが のらない（斜線で 表示）。
- **タコは おいた 人の ねこ 2匹ぶん** の 票に なる（とられない）。CPU どうしの 比較で 1匹ぶんだと タコを つかう 手が 損だった（4人戦 12局：つかった 人の 平均 30.1点・つかわない 人 45.6点。2匹ぶんでは 44.7点・33.7点）。
  - 「タコが つかわれない」のは 票の 重さより CPU の 判断の せいだった。CPU が「逃がせる 相手が 2匹 以上」の ときしか タコを 考えなかったのを、票の ためだけでも 考える ように した（4人戦 12局：つかう 人 52%→75%、つかった 人と つかわない 人の 平均点は ほぼ 同じ 32.6点・32.1点）。3票に すると つかった 人の ほうが 平均点が ひくく なった（28.6点・31.7点）ので 2票の まま

### おわりと 点数
- 盤が うまるか、**もう あたらしい なわばりが できなく なったら** おしまい。または 山札と タイルが なくなるか、全員 つづけて パスしたら おしまい。
  - 判定：のこりの 空きマスを ぜんぶ 十字（いちばん こまかく 区切る 形）で うめた と 考え、空きマスの 角を ふくむ 面が どれも トンネルを ふくめば、どう うめても なわばりは ふえない（`canStillScore`）。
- 点 ＝ なわばり ＋ 魚屋 ＋ とった ねこ。完成して いない 面・魚屋は 0点。

数値は `main.js` の 先頭（`RULES_BY_N`・`DECK_DEF`・`TAKO_PER_PLAYER`）で かえられます。

## しくみ（main.js）
- `cells[81]`：`null` か `{ m: 猫道(4bit N=1 E=2 S=4 W=8・回転ずみ), cat: プレイヤー番号 | null }`
- **面は タイルの 角（格子点 10×10）で 計算** する。1つの 格子点の まわりの ¼マス 4つは かならず つながり、
  となりの 格子点とは「その あいだを 猫道が 横切って いない」ときだけ つながる（`connH` / `connV`）。
  格子点の 塗りつぶしで 面が 出る（`computeFaces`）。点は 面が かかった タイルの まい数（`f.pts`）
- 面に 面した 猫道の タイル（その ¼マスに 猫道が ふれて いる タイル）の ねこを 数えて 持ち主を きめる
- CPU は 状態を コピーして 同じ ルール関数で 1手 先を 読む（`cpuChoose`）

## CPU どうしで ためした ようす（2026-09-29 版）
- 盤は 最後まで うまり、2人 48手・3〜4人 80手 前後で おわる
- なわばりは 1ゲーム 4〜10こ。合計は 2人 13〜45点、4人 5〜30点ほどで、1つの 面の 総取りは おきにくく なった
- 盤の 端・角に 1〜2点の 小さな なわばりが たくさん できる（端が 境界に なったため）。最小 面積の しばりを 足すか 検討
- CPU は 大きな 輪を ねらわない（1手 先しか 読まない）ので、ひとが 大きく かこむと 強い はず
- ためした けれど やめた ルール：
  - 「1本 つなげれば よい」→ 猫道の 端が ぜんぶ ふさがって、道の ある タイルを おけなく なる
  - 「盤の 端も 境界（トンネルなし）」→ 最後に 外がわ ぜんぶが 1つの 巨大な 面に なり、そこを とった 人が ほぼ 総取り → トンネルを つけて 解決
  - 「盤の 端は 境界に しない」→ 大きな 面の 総取りは へったが、1つの 大きな 面で 決着しがちだった

## 今後 足す 候補
- 特殊マス：施設（段ボール・ひなた・魚屋）で 面の 点を ふやす、二眼で 安住
- 効果：浸食（猫道を 切って 相手の 輪を くずす）、ボス猫、猫街の ギミック（きまぐれ・タコ大王）
- ChatGPT 案の 特殊効果 3種：ひなた（その 面 +2点）・猫じゃらし（となりの 自分の ねこを 1匹 うごかす）・タコ（となりの ねこを 手もとへ）
- 大きな 面の 点の 圧縮（4区画で 4点、以降 4区画ごとに +1）は まだ 入れて いない
- 特殊な 手（タイルを おく かわりに 1回）：ボス猫（盤の 自分の ねこ 1匹と 交換。2票ぶん）
