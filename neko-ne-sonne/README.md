# ネコネソンヌ（neko-ne-sonne）試作

囲碁の「陣取り・壁による死活」と、カルカソンヌの「タイル配置・多数派」を あわせた、ねこの なわばり 陣取り ゲーム。
猫街ろまん（tap-on-neko）の 4柄の ねこが 駒です。

このフォルダは 画像も ふくめて **これだけで 動きます**（HTML / CSS / Vanilla JavaScript、通信・保存なし）。
専用リポジトリ `neko-ne-sonne` を つくったら、フォルダの 中身を そのまま うつせば OK です
（左上の「‹ 猫街ろまん」リンク `../app/` だけ 書きかえてください）。

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の 入口 |
| `main.js` | ルール（盤・区画・浸食・得点）と CPU と 描画。ルールの 関数は 描画と わけて ある |
| `style.css` | 見た目（猫街ろまんと 同じ 配色＋碁盤の 木目） |
| `images/cat-*.png` | 4柄の ねこ（3×3 スプライト。tap-on-neko から コピー） |

## ルール（試作版）

### 盤と タイル
- 盤は **9×9**。まん中の 十字タイルから はじめ、枠の 外へは ひろがらない。
- タイルの 4辺は **道**（黒い 線）か **壁**（茶色の へい）。
- 手番の はじめに 山札から 1まい 引く。**手札は 3まいまで**（はじめは 2まい）。
- 手札を 1まい えらび、**となりと 辺が ぴったり あう** ように おく（道には 道、壁には 壁）。壁コマの ある 辺は どちらでも よい。
  回転を ふくめると 16とおり すべての 辺の 組みあわせが つくれるので、どんな 穴にも どれかの 形は はいる。
- どの 手札も おけない ときは 1まい **すてて** よい（番を つかった ことに なる）。

### おいた あと（どれか 1つ・しなくても よい）
| 行動 | 中身 |
| --- | --- |
| 🐾 ねこ | **いま おいた タイルの 上** に おく。おいて 区画が 完成しても おける |
| 👑 ボス猫 | 1人 1匹。2匹ぶんに 数え、その マスと 上下左右は 浸食されない |
| 🧱 壁コマ | 未完成の 区画の 道の 辺に おいて ふさぐ（区画を わける／とじる） |

### 区画・陣地
- 道で つながった マスの かたまりが **区画**。道が 空きマスへ ぬけて いなければ **完成**（盤の 外周は 壁）。
- 完成した 区画は、ねこ（ボスは 2）が いちばん 多い 人の **なわばり**。同数なら だれの ものでも ない。
- ねこは 盤に のこる（囲碁の 石と おなじ）。**点は さいごに まとめて 数える**。
- 施設（📦段ボール・☀️ひなた・🐟魚屋）が **2つ 以上** ある なわばりは 🛡️**安住の地**（二眼）で、浸食されない。

### ⚔️ 浸食
- 条件：じぶんの **完成した** なわばり A と、相手の 完成した なわばり B が となりあい、
  A の じぶんの ねこの かず ＞ B の 持ち主の ねこの かず（ボスは 2）。
- タイルを おく かわりに、手札で B の 境目の マスを **上書き** する。上書きする タイルは A がわに 道が むいて いる こと（ほかの 辺は あわなくて よい）。境目の 壁コマは こわれる。
- 上書きした マスには **かならず じぶんの ねこ（か ボス猫）を おく**。手もとに ねこが いなければ 浸食できない。
- 上書きできない マス：ねこが いる／ボス猫の マスと 上下左右／一度 上書きされた マス（🐾ふみかため）／安住の地。
- はじき出された タイルは やられた 人の 🎁**おみやげ**（さいごに 1まい 1点）。
- 「1マス 1回まで」なので 浸食の 回数は 81回が 上限。取りあいの 往復は おきない。

### おわりと 点数
- 全員が つづけて パス／山札と 手札が ぜんぶ なくなる／盤が うまって だれも 浸食できない、の どれかで おしまい。
- 完成した なわばり：マス数 ＋ 📦2・☀️1・🐟5（魚屋は 1区画 1軒まで）。
- 未完成の 区画：ねこが いちばん 多い 人に はんぶん（切りすて）。
- 同数で ならんだ ときは、その 点を さらに はんぶんずつ。
- おみやげ 1まい 1点。2人の ときは 後手（はちわれ）に コミ 3点。

## データ構造（main.js）
- `cells[81]`：`null` か `{ m: 道の辺(4bit N=1 E=2 S=4 W=8・回転ずみ), fac, cat: {p, boss}, stomped }`
- `walls[162]`：辺ごとの 壁コマ（辺の 番号は 西／北がわの マスの 東=×2・南=×2+1）
- 辺の つながりは 保存しない。「両がわの マスが 道・壁コマなし」から 毎回 計算（`passable`）
- 区画は 毎回 まるごと フラッドフィル（`computeRegions`）。壁で わかれる・上書きで かわるので 差分管理は しない
- CPU は 状態を コピーして 同じ ルール関数で 1手 先を 読む（`cpuChoose`）
