# tap-on-neko（猫街ろまん 〜Cat city Romance〜）

タップだけであそべる、**ねこと飼い主の日常ゲーム**です。タイトル画面から 2つのモードを選べます。

| モード | 中身 |
| --- | --- |
| **一週間モード** | 「街と、その白い壁」（[throw-on-tako](https://github.com/pikaring/pikaring-throw-on-tako)）の 4人（ナオ・フミ・マキ・チカ）の だれかに なって、ねこと 日曜から 土曜までの 7日を すごす。朝ごはん → 授業 → ほうかご → 夜の あそびを くりかえし、土曜の「ねこ じまん 大会」まで の ミニゲームの 合計で **ハイスコア** を めざす |
| **エンドレスモード** | もとの **高齢者向けの「猫のお世話＆脳トレ」**。制限時間・ゲームオーバーなし（下の「あそびかた」以降は この モードの 説明） |

バックエンドなし（HTML / CSS / Vanilla JavaScript のみ）で、セーブデータは LocalStorage に保存します。

**紹介ページ → https://pikaring.github.io/tap-on-neko/**
**あそぶ → https://pikaring.github.io/tap-on-neko/app/**

### ホーム画面に追加している場合

以前ホーム画面に追加した端末は、アイコンの起動先が `/tap-on-neko/`（紹介ページ）に
なります。紹介ページは**全画面表示で開かれたときだけ `app/` へ自動で移動**するので、
アイコンからは今までどおりゲームが直接開きます（`index.html` 冒頭の数行）。
ゲームの 入口（`app/`）は タイトル画面に なったので、エンドレスモードは「エンドレスモード」を 1回 押してから はじまります。

飼い主（4人）と ねこ（4柄）を えらび、**日曜に はじまり 土曜の 大会で おわる** 7日を すごします。1日は 4つの 時間で（土曜は あさと 大会の 2つ）、どれも ミニゲームで 点数が 入ります。

| 時間 | 場面 | ミニゲーム | 点数の 種類 |
| --- | --- | --- | --- |
| あさ | 家で ねこに ごはん | あさごはん クイズ 3問（ねこ・たべもの・いきもの・くらしと きせつ を まぜて 出す） | 🐾 ねこと なかよし |

| ひる（日） | ともだち 1人と 商店街へ かいもの | おつり早押し 4問。ともだちごとに ちがう **アイテム** が 手に 入る（下の 表） | 🤝 ともだち |

## あそびかた（エンドレスモード）
1. 「あそぶ（クイズ）」で**難読漢字の読みクイズ**。正解すると **あそびゲージ +25**・なかよし度 **+2**
   （ハートが浮かび、猫が喜ぶ）
2. 「ごはんを あげる（クイズ）」で**ことば穴うめ／かげあてクイズ**。正解すると
   **おなかゲージ +3目盛**・なかよし度 **+3**
3. **猫を直接タップすると、いつでもなでられる**（ゲージもなかよし度も動かない、ふれあいだけ）
4. どちらのゲージも**あと1回分（3目盛）の空きがないあいだはそのお世話はおやすみ**。
   時間がたつと減っていき、0になると猫が「おなかが すいたニャー」
   「あそんで ほしいニャー」とおねがいしてくる
5. なかよし度 **10 / 40 / 90 / 160 / 260 / 400 / 600 / 850 / 1200** で部屋に小物が増える（全9種）
6. なかよし度・ゲージ・猫の柄は自動保存され、次に開いたときに引き継がれる
7. 猫の柄は「ねこを かえる」からいつでも変更できる（きじとら／ちゃしろ／くろねこ／はちわれ）

## おなかと あそびのゲージ

無限にタップし続けられないようにするための仕組みです。`main.js` の先頭付近で調整できます。

ゲージは**10目盛**で、目で数えられるように1つずつ区切ってあります。
ボタンと同じ側（おなか＝左／あそび＝右）に置いています。

| | おなか（左） | あそび（右） |
| --- | --- | --- |
| ふえる量 | ことばクイズ正解 **+3目盛**（4回で満タン） | かんじクイズ正解 **+3目盛**（4回で満タン） |
| 1目盛 減るのに | **36分**（0になるまで6時間） | **18分**（0になるまで3時間） |
| おやすみの目盛 | **8目盛以上**（あと3目盛の空きがない） | **8目盛以上**（あと3目盛の空きがない） |
| 次にできるまで | **108分**（3目盛ぶん） | **54分**（3目盛ぶん） |
| おやすみのとき | 「おなかは いっぱいだニャ。ごちそうさまニャ」 | 「たくさん あそんだニャ。すこし やすむニャ」 |
| 0のとき | 「おなかが すいたニャー」 | 「あそんで ほしいニャー」 |

判定は**残りの目盛だけ**で決まります（`main.js` の `meterResting()`）。
1回で3目盛ふえるので、**3目盛ぶんの空きができるまでお休み**です。

- 少し減っただけで再開できると、1分待つだけで何度でも遊べてしまう
  （理論上1日7200ポイント稼げました）
- 逆に「満タンから0になるまでお休み」にすると、ゲージが半分まで減っていても
  お世話できず、目盛の見た目と動きが食い違ってしまう

その間をとって「あと1回入る空きができたら、また できる」にしています。
1日の上限は理論値135ポイント（あそび29回＋ごはん16回）で、最後の小物（1200点）まで
ぶっ通しでも約9日、1日2サイクルなら約67日かかります。

- 減る量は**閉じている間も実時間で計算**します（`lastVisit` との差から算出）。
  開いている間は1分ごと、別の画面から戻ったときはその場で更新します
- 古いセーブデータ（0〜100で保存されたもの）は、読み込み時に10目盛へ自動換算します
- おやすみのボタンは灰色の「やすみ色」になりますが、押しても大丈夫です
  （猫が「いっぱいだニャ」と答えるだけで、ペナルティはありません）
- 1サイクルで得られるなかよし度は最大20（あそび8＋ごはん12）。
  ゲージが回復するたびに遊べば1日112ポイントが上限、1日2サイクルなら40ポイント。
  全9種の小物がそろうまで、**熱心に遊んで11日・1日2サイクルで30日**の想定です
  （しきい値は `main.js` の `UNLOCKS` の `point` で調整できます）
- 猫を直接タップしてなでる分はゲージに影響しません（いつでも何度でもふれあえます）

## 何もしていないときのポーズ

ずっと同じ姿だとさみしいので、猫の気持ち（ゲージの状態）に応じて
**7秒ごとにポーズをゆっくり切り替えます**（`main.js` の `IDLE_POSES`）。
お世話中やクイズ中は割りこみません。

| 気持ち | 条件 | ポーズ |
| --- | --- | --- |
| まんぞく | 両方おやすみ中 | こうばこずわり／ねむる／のびてねそべる（「おなかも こころも いっぱい… すーすー」） |
| あそびたい | あそび 0 | **おなかを見せてかまって**／あそびの おさそい／しっぽを追いかける |
| おなかすいた | おなか 0 | 前足を上げておねだり／見上げる／首をかしげる |
| よる | 17:00〜4:59 | ねむる／こうばこずわり／のびてねそべる |
| ふつう | 上記以外 | おすわり／けづくろい／こうばこずわり／あくび／うしろむき／しっぽ／びっくり など |

2枚目のシートが無い柄では、1枚目だけで使えるポーズに自動で置きかわります
（現在は4柄すべて2枚目があります）。

## 設計上の約束（高齢者向けの配慮）

エンドレスモードの 約束です。一週間モードも シングルタップだけ・大きな 文字と ボタンは 同じですが、
早押しの ミニゲームだけ 時間で 点数が かわります（時間切れでも ゲームオーバーには なりません）。

- 操作は**シングルタップのみ**。スワイプ・ドラッグ・長押しは使わない
- ボタンのタップ領域は 48px 以上（スマートフォン実測 約175×153px）、文字は 22〜40px
- 表記はすべてひらがな中心の日本語。英語表記なし
- **制限時間・ゲームオーバー・病気・死亡は一切なし**
- 久しぶりに開いても「まってたニャ！」とポジティブに迎える
- 不正解でもペナルティなし（「おしい！もういっかい！」で何度でも再挑戦）
- 時間帯で挨拶が変化（朝 5:00–10:59 / 昼 11:00–16:59 / 夜 17:00–4:59）

## 猫の画像（スプライトシート）

猫の画像は **3×3＝9ポーズを1枚にまとめたスプライトシート**（1020×1020px / 1セル340px）で、
柄が4種類あります。

柄ごとに**2枚**（お世話の反応9ポーズ＋ひとりでいるときの8ポーズ）あります。

| 柄 | お世話の反応 | ひとりでいるとき |
| --- | --- | --- |
| キジトラ ＝ 既定 | `images/cat-kijitora.png` | `images/cat-kijitora-relax.png` |
| くろねこ | `images/cat-kuro.png` | `images/cat-kuro-relax.png` |
| ハチワレ | `images/cat-hachiware.png` | `images/cat-hachiware-relax.png` |
| 茶白（ちゃしろ） | `images/cat-chashiro.png` | `images/cat-chashiro-relax.png` |

2枚目の有無は `main.js` の `CAT_PATTERNS` の `relax` で持っています。`false` の柄では
2枚目が必要なポーズを自動的に飛ばすので、絵が足りなくても破綻しません。

8枚すべて**同じ縮尺（0.9373倍）・同じ立ち位置**に揃えてあるため（各セルの下端・横中心の差が0px）、
シートやポーズをまたいでも猫の大きさと足の位置は変わりません。

縮尺が変わったときは、画面上の大きさが変わらないよう `style.css` の `.cat-stage` の幅を
**（前の幅 × 前の縮尺 ÷ 新しい縮尺）**に調整します。

### 2枚目のポーズ（ひとりでいるとき）

| 位置 | ポーズ | クラス |
| --- | --- | --- |
| 上段 中央 | おなかを見せてかまって | `is-pose-belly` |
| 上段 右 | けづくろい | `is-pose-groom` |
| 中段 左 | しっぽを追いかける | `is-pose-tail` |
| 中段 中央 | こうばこずわり | `is-pose-loaf` |
| 中段 右 | のびてねそべる | `is-pose-stretch` |
| 下段 左 | びっくり | `is-pose-surprised` |
| 下段 中央 | 見上げる | `is-pose-lookup` |
| 下段 右 | うしろむき | `is-pose-back` |

上段 左は柄によって絵が違うため使っていません（キジトラは仰向け、他は座り姿）。

遊ぶ人は**初回起動時の「どの ねこに する？」**と、部屋の上にある
**「ねこを かえる」ボタン**でいつでも柄を選べます（選択は LocalStorage に保存）。
選択画面は2列×2段のカードで、360×640pxの小さな端末でもスクロールなしに収まります。
既定は `main.js` の `DEFAULT_CAT`、選べる柄は `CAT_PATTERNS` で定義しています。

```js
var CAT_PATTERNS = [
  { id: 'cat-kijitora',  name: 'きじとら' },
  { id: 'cat-chashiro',  name: 'ちゃしろ' },
  { id: 'cat-kuro',      name: 'くろねこ' },
  { id: 'cat-hachiware', name: 'はちわれ' }
];
var DEFAULT_CAT = 'cat-kijitora';
```

柄を足すときは、画像を `images/` に置いて `CAT_PATTERNS` に1行足すだけです。

`main.js` が読み込みに成功したときだけ `.cat--image` クラスと `--cat-image` を付けるので、
画像が無い・読めない環境では絵文字（🐈）のまま遊べます。

| 上段 中央 | よろこぶ | `is-pose-happy` | 「なでる」 |
| 上段 右 | ごはんを食べる | `is-pose-eating` | クイズ正解 |
| 中段 左 | あくび | `is-pose-morning` | 朝 5:00–10:59 |
| 中段 中央 | 遊びの誘い | `is-pose-noon` | 昼 11:00–16:59 |
| 中段 右 | ねむる | `is-pose-night` | 夜 17:00–4:59（通常ポーズも これ） |

| 下段 中央 | バンザイ | `is-pose-celebrate` | アイテム獲得 |
| 下段 右 | 首をかしげる | `is-pose-thinking` | クイズ表示中 |

### 画像を作り直す・柄を増やすとき
1. 生成AIに `docs/cat-sprite-prompt.md` のプロンプトを渡して、3×3の9ポーズを1枚で出力する
2. `tools/build_cat_sheet.py` に通す（市松模様やベタ背景の除去 → 9セルを共通の縮尺・
   横中央・下ぞろえに整列 → 透過PNG出力）。**複数枚を一度に渡すと共通の縮尺が使われる**ので、
   柄を足すときは既存の画像も一緒に渡し直すこと

   ```sh
   python3 tools/build_cat_sheet.py images \
     kijitora.jpg:cat-kijitora chashiro.jpg:cat-chashiro \
     kuro.jpg:cat-kuro hachiware.jpg:cat-hachiware \
     kijitora2.jpg:cat-kijitora-relax kuro2.jpg:cat-kuro-relax \
     hachiware2.jpg:cat-hachiware-relax
   ```

   共通の縮尺は渡した画像だけで計算されるため、**猫のシートは毎回すべて一緒に渡す**
   （1枚だけ作り直すと、その猫だけ大きさがずれる）。
   小物や動物のように性質が違うものは、別に実行する

   スクリプトは背景色を画像の外周から学習するので、市松模様・白ベタ・色つきの市松模様の
   どれでも除去できます。消し残りの小さな塊（平均色が背景に近いもの）も自動で取り除きます
3. `pngquant --quality=70-95 --output images/cat-xxx.png images/cat-xxx.png` で軽量化

ポーズを増やす場合は、グリッドの列数・行数に合わせて `style.css` の
`background-size` と `background-position`、`main.js` の `POSE_CLASSES` を直してください。

## クイズの出題

ボタンごとに出す問題が違います。選択肢は表示のたびにシャッフルし、常に2列で並べます。

| ボタン | 問題 | 問数 |
| --- | --- | --- |
| あそぶ | **難読漢字の読み**（4択） | 100 |
| ごはんを あげる | **ことば穴うめ**（4択）と**かげあて**（3択）を混ぜる（`SILHOUETTE_ONE_IN = 4` で4問に1問くらいがかげあて） | 200 + 9 |

ことば穴うめの出題データは `questions-kotoba.js`（[tap-on-kotoba](https://github.com/pikaring/tap-on-kotoba)
の `app/questions.js` をそのままコピー）です。更新するときは上書きコピーするだけで、
内容は書き換えません。使うのは**穴うめの200問**（`KOTOBA_TYPES`）:

| 種類 | 問数 | 例 |
| --- | --- | --- |
| `y` よじじゅくご | 50 | 一石**〇**鳥 |
| `k` ことわざ | 50 | 猿も**〇**から落ちる |
| `i` かんようく | 100 | 顔が**〇**い |
| `d` かんじの よみ | 100 | **「あそぶ」で出題**（`KANJI_TYPES`）。漢字を大きく見せて読みを選ぶ |

正解すると、空欄に答えが入り、**よみと意味**を表示します。時間制限はないのでゆっくり読めて、
下のボタンが「ごはんを あげる」に変わります。押すと猫がごはんを食べてご褒美が入ります。

## ホーム画面への追加（PWA）

`manifest.json` と `images/icon-*.png`（32 / 180 / 192 / 512px）を用意してあります。
スマートフォンの「ホーム画面に追加」で猫のアイコンが並び、ブラウザのバーが出ない
全画面表示（`display: standalone`）で起動します。高齢の方がアプリのように使えるようにするためです。

アイコンはOS側で角を丸く切り取られるため、白い角が残らないよう**全面を塗った四角**にしています
（桜色から若草色のグラデーション。上にロゴ、下にねこ3匹）。`python3 tools/make_icons.py` で作り直せます。

## 部屋の背景

`images/room.jpg` を `.room--image` として適用しています（`background-size: cover` /
`background-position: left bottom`）。窓が切れないよう左下を基準に合わせています。
読み込みに失敗した場合は、CSSのグラデーション（クリームの壁＋茶色の床）のまま遊べます。

画像の床の帯は下から約31%で、猫の立ち位置（下から8%）と小物（下から2〜28%）は
すべてその範囲に収まるようにしています。
